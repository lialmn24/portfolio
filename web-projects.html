Maintenance Ticketing System

2026 · Class project

A web system for the school Maintenance Office. Staff file requests for materials or equipment, and each ticket moves through role-based approvals up to the school president.

My role: Solo developer. I built the whole system myself.

Case study and features
Challenge
Requests have to pass through several offices before approval.
What I built
A Laravel system with role dashboards and a Kanban-style board.
Result
Every request followed from filing to completion.
  • Three request forms: facilities, requisition, and repairs
  • Separate dashboards for each role
  • Maintenance board with New, Doing, Done columns
  • Laravel
